# 家常菜谱 Android App

一个轻量离线菜谱软件，适合先做成可安装 APK，再继续扩展云同步、上传菜谱和购物清单。

## 已实现功能

- 菜谱首页和今日推荐
- 搜索菜名、食材、分类和标签
- 分类筛选：全部、快手菜、家常菜、汤羹、主食、轻食
- 收藏菜谱，本地保存
- 自己输入菜名并保存到“自定义”菜谱
- 从自己会做的菜里随机生成周一到周日菜单
- 手动更改已生成的一周菜单
- 菜谱详情弹窗
- 用料、步骤、时间、难度、热量展示
- 按人数调整用料比例

## 建议继续开发的功能

- 添加/编辑自己的菜谱
- 购物清单，一键汇总缺少食材
- 冰箱库存，按已有食材推荐菜
- 每周菜单计划
- 图片上传和步骤图
- 云同步、账号登录、家庭共享
- AI 生成菜谱和营养建议

## 在线编译

推荐用 GitHub Actions：

1. 把 `RecipeBookApp` 上传到 GitHub 仓库。
2. 打开仓库的 `Actions` 页面。
3. 运行 `Build Android APK`。
4. 构建完成后，在 `Artifacts` 下载 `recipebook-debug-apk`。

也可以把整个目录导入 Android Studio、CodeMagic 或 Appetize 这类在线构建服务。
