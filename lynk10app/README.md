# 领克10 EV 远程监看（骁龙8295）

这是一个纯自用的最小版本，只保留三件事：

1. 车机后台维持加密连接；
2. 手机发起一次请求；
3. 车机保持四路 EVCam 风格的 Camera2 预览流，并把当前预览帧发回手机。

它不录像、不采音频、不做哨兵、不读车辆控制信号，也不保存历史图片。

## 安装与首次配置

1. 安装 `lynk10app-release.apk`，打开后允许相机和通知权限。
2. 点击“探测相机”，查看车机实际暴露出的 Camera ID。
3. 把前、后、左、右四个 ID 按顺序填入；可先试 EVCam 常用的 `2,1,3,0`，
   再根据四格实时画面调整。
4. 填写服务器地址、车辆代号和 NAS 中配置的 `VEHICLE_TOKEN`。
5. 点击“保存配置”和“开始守候”，再按提示允许忽略电池优化和“后台唤起权限”。
6. 手机打开中继网页。主手机首次输入 `OWNER_PASSWORD` 完成绑定，以后自动验证；
   其他设备每次会话需要输入密码。

公网服务器必须使用 `wss://`。`ws://127.0.0.1` 只留给 ADB 本机联调。

## 8295专项处理

- APK只保留 `arm64-v8a`；
- 沿用 EVCam 的 `TextureView + SurfaceTexture` 重复预览流，不使用按需
  `ImageReader` 单帧抓拍；
- Camera 特性在探测后缓存，抓拍时不再重复查询车机 Camera HAL；
- 手机请求到来时直接复制四路当前预览帧，避免反复开关摄像头；
- 图片长边限制为1600像素、JPEG质量82，兼顾识别度和蜂窝网络流量；
- Android 14及以上使用远程消息前台服务维持控制通道；
- 收到抓拍请求后短时持有唤醒锁；四路预览由相机前台服务维持。

## 实车适配边界

骁龙8295有足够性能，但能否读取原车360摄像头，最终由领克10 EV固件的 Camera HAL、SELinux 和应用签名权限决定。若“探测相机”看不到四路环视，普通 APK 无法仅靠提高权限解决；若只能看到 `PRIVATE` 输出，则需要根据探测报告接入 OpenGL Surface 兼容层。

第一次上车测试后，请保留“复制报告”得到的相机探测内容和抓拍错误。报告不包含车机密钥。
